{% comment %} Click-activated tooltip with pointer events (supports links). Required: - id: unique id for the tooltip body (used by aria-controls) - content: HTML string for the tooltip body Optional: - trigger_text: visible trigger label (default: "More info") - trigger_icon: USWDS sprite icon name (e.g. "info"); when set, renders an icon instead of text - trigger_label: accessible name for icon triggers (default: "More information") - trigger_class: extra classes on the trigger button - show_close: if "false", hide the close button (default: shown) - width: CSS width for the tooltip body (e.g. "80cqw", "12rem"). For cqw units, put class "custom-tooltip-container" on the layout ancestor that should define the container size. The tooltip body centers horizontally on that container. Example: {% capture tip_html %} Data source: USAspending.gov {% endcapture %} {% include components/_custom-tooltip.html id="data-source-tip" trigger_icon="info" trigger_label="More information about spending" content=tip_html width="80cqw" %} {% endcomment %} {% if include.show_close != "false" %} {% endif %} {{ include.content }}
