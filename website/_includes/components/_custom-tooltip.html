{% comment %} Click-activated tooltip with pointer events (supports links). Required: - id: unique id for the tooltip body (used by aria-controls) - content: HTML string for the tooltip body Optional: - trigger_text: visible trigger label (default: "More info") - trigger_icon: USWDS sprite icon name (e.g. "info"); when set, renders an icon instead of text - trigger_label: accessible name for icon triggers (default: "More information") - trigger_class: extra classes on the trigger button - show_close: if "false", hide the close button (default: shown) - width: fallback CSS width for all breakpoints (e.g. "80cqw", "12rem") - width_phone / width_tablet / width_desktop: per-breakpoint widths. Any omitted value falls back to `width`, then to the stylesheet default. For cqw units, put class "custom-tooltip-container" on the layout ancestor that should define the container size. The tooltip body centers horizontally on that container.
