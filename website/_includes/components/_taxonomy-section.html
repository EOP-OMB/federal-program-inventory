FPI Taxonomy

The FPI Taxonomy is a classification system designed to provide a more systematic framework for logically organizing Federal programs and the information associated with those programs. Components of the classification system include Categories, Sub-Categories, Government-wide Objectives, and Program Outcomes. There are currently 123 Government-wide Objectives in the taxonomy. Each program in the FPI is mapped to a Government-wide Objective, and up to three Program Outcome(s) to which they are best aligned. A small number of GWOs are currently not mapped to any programs.
